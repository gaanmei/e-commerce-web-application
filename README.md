# T-Town Autoparts - E-Commerce Web Application

A responsive e-commerce platform for automotive parts based in Tamenglong, Manipur. Built as a mini project at NIELIT Imphal.

## 🔗 Live Demo
**https://gaanmei.github.io/e-commerce-web-application/**

## ✨ Features
- Product listing for autoparts
- Responsive design for mobile & desktop
- Category filtering and search
- Shopping cart UI
- Clean, modern UI with custom CSS

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- Google Fonts (Barlow Condensed)
- Git & GitHub

## 📁 How to Run
1. Clone the repo: `git clone https://github.com/gaanmei/e-commerce-web-application.git`
2. Open `index.html` in your browser
